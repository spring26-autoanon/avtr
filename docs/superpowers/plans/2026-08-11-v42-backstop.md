## Global Constraints

- `serving_exp/patches/e2_forced_ret.py`, `~/serve_demo.sh` (box), `~/channel.py.v41_DEMO_LOCKED` (box) are FROZEN — no edits.

- Native fires are NEVER gated by holdoff or refractory — only the backstop's own arming is.
- All env parses use the established early-parse try/except shape with a safe default (a malformed env var must degrade, never raise inside the TaskGroup).

- Sentinel string (exact, both in templates and skip check): `no reference available`.
